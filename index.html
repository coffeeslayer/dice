Search filters

The Playwright runner uses a dedicated Chrome profile because current Chrome blocks automation of the regular profile. Configure DICE_EMAIL and DICE_PASSWORD in the local, Git-ignored .env file for automatic sign-in, or sign in manually in that window. The session is kept for future runs. See README.md.

Playwright Easy Apply runner

The companion runner opens a dedicated Chrome profile. Sign in to Dice in that window once; it keeps the session for future runs. After each application it returns to the filtered search and reloads the results. It records successful applications locally and skips jobs already marked Applied or previously processed.

See README.md for setup and run instructions. The runner prints startup progress. Use preview mode to inspect matches; python apply_jobs.py --apply submits eligible results automatically without an additional confirmation prompt.
